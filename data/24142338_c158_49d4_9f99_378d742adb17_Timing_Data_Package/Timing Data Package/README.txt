This data package consists of the timing information for Atlantic salmon smolt migration from 9 rivers:

Dee (Wales) 1997 - 2019
Frome (England) 2006 - 2020
Tamar (England) 2005 - 2019
Bresle (France) 1996 - 2021
Oir (France) 1986 - 2021
Scorff (France) 1997 - 2021
Bush (Northern Ireland) 1997 - 2020
Burrishoole (Ireland) 1970 - 2019
North Esk (Scotland) 1975 - 2013

The data are packaged with the scripts used to create them from the source. Source data are not included, but can be found either online or obtained from the owner. Source data are linked to in the graph database via DERIVED_FROM relationships between Metadata nodes.
